# 🌸 NariAdhikar – Women's Rights & Awareness Website

**NariAdhikar** is a web-based platform designed to spread awareness about women's rights, legal support, safety, and empowerment. It aims to help users explore useful information and resources through a simple, accessible interface.

## ✨ Features

- ⚖️ **Women's Legal Awareness** – Information about women's rights and legal protections.
- 🤖 **AI Legal Assistance** – An interface for legal-awareness support.
- 🎨 **7 Theme Options** – Light, Dark, Pink, Nature, Purple, Blue, and High Contrast.
- 📱 **Responsive Design** – Designed to work across desktop and mobile screens.
- 💬 **Floating Chatbot** – Quick access to the website's chatbot.
- 🧭 **Easy Navigation** – Organized sections for accessing website information.
- ♿ **High-Contrast Theme** – An additional theme option for improved readability.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages / Netlify for deployment

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/payalchougale/WOMENS-RIGHTS.git
```

### 2. Open the project

Open the downloaded folder in Visual Studio Code.

### 3. Run the website

Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.
